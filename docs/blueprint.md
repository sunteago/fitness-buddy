# **App Name**: Fitness Buddy

## Core Features:

- Profile Setup: Allow users to set up their profile with details like age, gender, height, weight, and fitness goal (lose fat, gain muscle, maintain).
- Nutrition Logging: Enable users to log their daily meals by inputting food name, portion size, and calorie count.
- Exercise Logging: Enable users to track their workouts by recording exercise name, duration, and estimated calories burned.
- Daily Summary Dashboard: Display a daily summary that includes BMI, total calories consumed, total calories burned, and net calorie balance.
- AI-Powered Personalized Suggestions: Suggest adjustments to calorie intake or exercise based on the user's logged data and fitness goals. The tool will decide which info to display depending on if they are on track to reach their daily and/or weekly fitness goals.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) to convey a sense of health and openness.
- Background color: Soft, desaturated blue (#E0F8F7).
- Accent color: Soft Green (#B0E2FF), signaling good progress and health benefits.
- Clean, sans-serif font for readability across all devices.
- Use consistent and modern icons for navigation and data representation.
- Mobile-first, responsive layout with clear, structured sections for easy navigation.
- Subtle transitions and animations to provide feedback and enhance user experience.
